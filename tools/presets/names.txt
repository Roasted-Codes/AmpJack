# What ships in xw.presets, in panel order: SHORT NAME | file | DESCRIPTION
#
# FLAT is index 0 on the console and CUSTOM comes after the last line here; neither is listed
# (their descriptions are in xbox360/eq_360.c).
# SHORT NAME: the panel row, at most 20 characters from the panel font only:
#   A-Z 0-9 space - % + : / . < >   (xbox360/hud_panel.c FONT_CHARS)
#   It is also the preset's id (FNV-1a), which xw.settings saves: renaming a preset makes a
#   saved choice of it load as FLAT.
# file: relative to tools/presets: upstream/*.astroeq (TheZEFERENCE, credit ZaliaS) or
#   xw/*.xweq (this project's own; the format is explained in xw/bass-boost.xweq).
# DESCRIPTION: what the panel's help line says while the cursor is on PRESET: one line of at
#   most 36 characters (convert.py HELP_COLS refuses more), the same characters (no comma, no
#   apostrophe). What a player hears and what it is for, in everyday words, never numbers of
#   Hz or dB; honest about the trade-off. Written from each curve as it plays on this console
#   (convert.py prints it) and from its author's notes. The upstream presets were made for
#   Astro headsets, which are dark; on another headset they all lean bright, and the
#   descriptions say what they do here.
#
# The set is a menu of flavours for games on the 360 and the original Xbox, not every preset
# upstream: see the DROPPED lines at the end.
